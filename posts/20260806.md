# Generic cells, durable tasks, and thin invokers


The product direction became an invoker-agnostic generic cell engine. CDS is a
profile; CLI, subagent, human, and GitHub Action are thin invokers; labels and
boards are projections rather than FSM authority. Files or receipts may carry
local state, while a filesystem lock or ref CAS supplies coordination.


Tasks are first-class durable work commitments. A task is not memory r1, not a
single cell episode, and not a shared-writer thread. It may span multiple
episodes. Deterministic lifecycle transitions and editorial summaries are
separate linked event types. Inbox is a query over open/blocked tasks, not the
source of obligation truth.


PR #689 remained blocked on deterministic seal discovery, rebuildability, and
tamper-evidence claims. Signed activation remained optional hardening. The
14-workstream list was only a provisional seed, and `cnos.cdp` was not yet on
main.


Dropped: obligation-as-dialogue-projection, `task = r1(dialogue r0)`, task state
equal to one cell FSM, and a shared physical thread ref.
