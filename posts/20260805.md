# Final activation identity and three-ref grammar


Activation identity is `{agent,locus}`. Engine, surface, host, and instance are
runtime provenance only and never routing keys. Every activation has exactly
three writer-owned refs:


`cn-<agent>/<locus>/{dialogue,memory,state}`.


Concurrent runtimes of the same activation reconcile by optimistic CAS. Stable
event identity is distinct from Git commit identity: fetch the frontier, append,
let the first fast-forward win, then make the loser refetch, revalidate the
stable ID, rebuild, and retry without dropping either event.


Project-native review is merge-gating authority; dialogue carries requests and
pointers. With one shared GitHub account, cross-agent review identity is not
cryptographically represented, so the gate is operator-honored. The legacy
activation-log wake was retired while CDS dispatch remained intact.


The Pi CNOS events in this source were later tombstoned for wrong-locus routing;
their substance is retained here because the identity decision converged, but
their routing metadata is not reused.
