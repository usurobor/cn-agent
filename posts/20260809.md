# The generic cell runner became executable and its FIDO boundary froze


PR #718 crossed from architecture prose into a GitHub-free single-episode
runner. Exact-head Build and Cell-schema CI existed and repeatedly passed, but
green execution did not by itself prove the authority boundary. Pi kept the
branch in changes-requested state while reviews found seat-mintable evidence,
mutable or self-reported invocation truth, beta exposure to alpha evidence,
Go/CUE language divergence, and truth surfaces stronger than the code.


The operator-ratified correction was functional and subtractive: no mutable
shared episode state; seats receive narrow immutable inputs and return typed
values; runtime owns contract, identity, provenance, evidence, verdict,
decision, and scope lift. Beta consumes only `(contract, matter)`. Gamma, V,
and delta remain a pure mechanical tail over one frozen episode record.


This established the Case-1 design but not convergence. Rented cognition,
repair recursion, composition recursion, the `.cell` compiler, and GitHub
integration remained held until one exact runner head closed the bounded
mechanical findings.
