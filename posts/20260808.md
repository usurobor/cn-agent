# Recursive mechanization: settled ontology, bounded claims, evidence gate


PR #716 converged at `37d7285...` and merged as `cdfa4db...`; the `cnos.cdp`
planning hierarchy is now main-reachable project authority.


The operator ratified recursive-with-predicates architecture. Alpha and beta
exist at every depth. Compiled protocol runs when mechanically determined;
rented cognition is selected only by a deterministic typed predicate. Parent
alpha decomposes and parent beta composes accepted child receipts. A task may
span episodes. Runtime enforces alpha/beta isolation, gamma binds runtime
evidence, V verifies, and delta gates. Child class flow is parent-mediated.
Epsilon profiles and detects compilation candidates; a reviewed evolution cell
compiles them.


Hardening: predicates are pure over structured fields; determinism covers the
routing decision, not rented output; beta policy and bundle evidence are
runtime-owned; compiled decompositions carry provenance and invalidation;
attempt exhaustion opens a human gate or protocol gap. Mechanization metrics
must be paired with errors, overrides, rollbacks, coherence, and
transmissibility.


The frozen shipping line is generic runner -> CDS CLI/profile -> thin GitHub
adapter, in parallel with one dialogue primitive, post-handling cursors,
disposable inbox projection, and a minimum task record. S0 completed. S1
roadmap/taxonomy had not materialized. #711 still required an authoritative-body
repair and final Pi convergence; #717 required a CLI-first single-episode kernel
before repair or recursion.


Dropped: cognition only at leaves, cognitive or self-certifying gamma, fixed
CC-to-PC-to-WC peer pipeline, shared-writer threads, and framework-first runner
ordering.
